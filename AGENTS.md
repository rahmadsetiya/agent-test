# Agent Test Project

## Purpose

Sandbox repository for testing the OpenClaw coding-agent workflow.

## Commands

Run application:

python3 hello.py

Run tests:

python3 -m unittest discover -v

## Development Rules

- Keep implementation simple.
- Do not add dependencies unless necessary.
- Do not modify files outside this repository.
- All functional changes should include tests when applicable.

## Definition of Done

A task is complete when:

1. Acceptance criteria from the GitHub issue are satisfied.
2. Tests pass.
3. Final diff has been reviewed.
4. No unrelated changes are included.
5. Git status is clean after commit.
